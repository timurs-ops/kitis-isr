# КИТиС-ИСр-ДЭ — лестница подготовки к демоэкзамену

Учебный полигон по мотивам реального проекта [«Сайт расписания КИТиС»](https://berezovskija124-ctrl.github.io/kitis/desktop.html)
([исходники](https://github.com/berezovskija124-ctrl/kitis)). Мы не читаем «взрослый» код автора — мы **заново строим его ключевые части**,
шаг за шагом, от первого `<h1>` до PHP+MySQL. Каждый шаг — маленькое домашнее задание с автопроверкой и понятными критериями зачёта.

> Это учебные материалы, а не официальный сайт КИТиС. Данные расписания — реальный срез недели группы ИСр24-1 (16–22 ноября 2026).

## Начни отсюда

1. **[docs/STUDENT-START.md](docs/STUDENT-START.md)** — настройка за один вечер: GitHub, VS Code, Live Server, публикация на GitHub Pages.
2. **[docs/GRADING.md](docs/GRADING.md)** — как сдавать ДЗ и что такое «зачёт» (чтобы потом не было сюрпризов).
3. **[docs/AI-POLICY.md](docs/AI-POLICY.md)** — правила использования ИИ (спойлер: можно, но с защитой).
4. **[docs/RESOURCES.md](docs/RESOURCES.md)** — по 1–2 ссылки на каждый шаг, не больше.

## Данные

В [`data/`](data/README.md) — учебный срез реального расписания: одна группа, одна неделя, звонки, цвета предметов.
Формат намеренно простой (плоский JSON), чтобы не усложнять JS.
