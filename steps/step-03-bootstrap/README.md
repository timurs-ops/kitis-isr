# Шаг 03 · Неделя целиком (Bootstrap 5)

**Цель:** собрать страницу недели на готовой сетке. Bootstrap — «леса»: быстрый адаптив без ручных
media queries. Свою карточку пары из шага 2 **сохраняем** — фреймворк не заменяет твой CSS, а дополняет.

## Задание

### 1. Bootstrap локально (важно!)

Скачай `bootstrap.min.css`: [getbootstrap.su](https://getbootstrap.su/) → Download,
или [релизы twbs/bootstrap](https://github.com/twbs/bootstrap/releases) (архив `bootstrap-5.x.x-dist.zip`).
Положи файл в `vendor/bootstrap.min.css` **этой папки** и подключи:

```html
<link rel="stylesheet" href="vendor/bootstrap.min.css">
```

**Не CDN!** На экзамене интернета может не быть — привыкай к локальным зависимостям.
Bootstrap JS не нужен: дни пока статичные ссылки, оживим на шаге 5.

### 2. Стили карточки

Скопируй свой `style.css` из шага 2 в эту папку и подключи **после** bootstrap.

### 3. Разметка

- `nav.navbar` — бренд «КИТиС · Расписание»;
- `ul.nav.nav-pills` (или `nav-tabs`) — 6 пунктов дней Пн–Сб;
- `.container` → `.row` → **6 колонок** `.day-card` с классами `col-12 col-md-6 col-xl-4`;
- в каждой колонке: заголовок дня + карточки `.lesson-card` (твоя вёрстка из шага 2);
- таблица звонков `.table` (thead + tbody);
- footer.

### 4. Адаптив (Bootstrap делает сам классами col-*)

- **360px** — дни стопкой (по одному);
- **768px** — по два в ряд;
- **1280px** — по три.

Проверь кнопками ширины в check.html — автопроверка делает это же.
