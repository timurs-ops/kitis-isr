## Задание

В `index.html` этой папки (скелет уже есть, заполни TODO):

1. `<head>`: `lang="ru"` на `<html>`, charset utf-8, viewport, `<title>` со словом «Расписание».
2. `<header>` с **единственным** `<h1>`: «Расписание группы ИСр24-1».
3. `<main>` → `<section>` дня:
   - `<h2>` «Среда, 18 ноября»;
   - `<ol>` из трёх `<li>` — пары по порядку (порядок важен → нумерованный список);
   - в каждом `<li>`: время в тегах `<time>`, предмет, преподаватель, аудитория.
4. Таблица звонков: `<table>` → `<thead>` (заголовки `<th>`: Пара, Начало, Конец) + `<tbody>` (6 строк).
5. `<footer>` с подписью «Учебная работа».
6. **Никаких** `<style>`, `style="…"`, `<link rel="stylesheet">`, `<script>`. Только теги и смысл.
