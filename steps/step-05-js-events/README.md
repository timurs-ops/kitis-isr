# Шаг 05 · Дни, избранное, таймер (JS: события + localStorage)

**Цель:** страница оживает. Кнопки дней переключают расписание, избранное группы переживает
перезагрузку, таймер показывает «до конца пары N мин» — и всё это можно проверить в любую минуту
через демо-время `?now=` (идея взята с настоящего сайта КИТиС).

## Контракт (соблюдай точно — по нему работает автопроверка)

- **7 кнопок** `.day-btn` с `data-day="0…6"` — уже в `index.html`. Активная кнопка — класс `.active`.
- Клик по кнопке → `.active` переезжает на неё, `renderDay(i)` рисует день.
- **Избранное:** кнопка `#fav-btn`.
  - клик: если в `localStorage['kitis-de:fav']` уже есть `'ИСр24-1'` — убрать ключ, иначе записать;
  - `aria-pressed="true"/"false"` на кнопке отражает состояние;
  - при загрузке страницы состояние восстанавливается из localStorage.
- **Демо-время:** адрес вида `index.html?now=2026-11-18T10:30`:
  - страница открывает день из `now` (среда → кнопка Ср активна);
  - текущая пара (start ≤ now < end) получает класс `.current` на своей карточке;
  - `#timer` показывает «До конца пары: N мин», где **N = Math.ceil(оставшихся секунд / 60)**.
- **Без `?now`:** открывается понедельник, таймер считается по реальному времени
  (если пар сейчас нет — `#timer` пустой или «Пар нет»).

## Демо для самопроверки

```
index.html?now=2026-11-18T10:30
```
Среда, 10:30 → идёт 2-я пара «Экономика отрасли» (10:10–11:40) → до конца **70 мин**.
Другой момент: `?now=2026-11-20T09:00` — пятница, «окно» до 4-й пары (бонус: покажи «Следующая пара 13:50»).

## Подсказки

- `new URLSearchParams(location.search).get('now')` → строка или null; `new Date('2026-11-18T10:30')`.
- Индекс дня: найди в `SCHEDULE.days` день с `date === now.toISOString().slice(0,10)` (осторожно с часовым
  поясом: проще сравнивать локальные год-месяц-день через `getFullYear/getMonth/getDate`).
- `document.querySelectorAll('.day-btn').forEach(btn => btn.addEventListener('click', …))`.
- `localStorage.getItem / setItem / removeItem`.
- Таймер: `setInterval(tick, 1000)`; в `tick` сними `.current` со всех карточек, найди текущую пару,
  повесь класс, обнови `#timer`.
- Перенеси свой `renderDay` из шага 4 (и не забудь про «Пар нет» и «Дистант»).
