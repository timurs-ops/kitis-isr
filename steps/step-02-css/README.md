# Шаг 02 · Карточка пары (чистый CSS)

**Цель:** сверстать карточку «как на настоящем сайте»: цветная полоска слева, номер в цвет предмета,
плавный градиент к белому. **Без Bootstrap** — только свой CSS. Bootstrap придёт на шаге 3 как леса,
но карточку ты должен уметь сделать руками.

## Спецификация

Карточка `.lesson-card`:
- `display: flex; align-items: center; gap: 14px;`
- `border-left: 5px solid var(--subject-color);` — полоска предмета;
- `border-radius: 12px; padding: 14px 18px;`
- `background: linear-gradient(90deg, ОТТЕНК 0%, ОТТЕНК-СВЕТЛЕЕ 45%, #FFFFFF 100%);`

Номер `.lesson-num`:
- 40×40px, `border-radius: 10px`, белый фон, `border: 1px solid #E3E6EB`;
- `color: var(--subject-color); font-weight: 700;` содержимое центрировано (flex).

Контейнер `.lessons`: flex-колонка, `gap: 10px` (карточки не слипаются).

## Цвета (из данных: один предмет — всегда один цвет)

| Предмет | `--subject-color` | оттенок 22% | оттенок 10% |
|---|---|---|---|
| Графический дизайн и мультимедиа | `#c4b478` | `#f2eee1` | `#f9f8f2` |
| Экономика отрасли | `#c478c2` | `#f2e1f2` | `#f9f2f9` |
| Физическая культура | `#78b5c4` | `#e1eff2` | `#f2f8f9` |

Переменную `--subject-color` задай **каждой карточке**: `style="--subject-color:#c4b478"` или отдельным классом.
Оттенки подставь в градиент готовыми значениями из таблицы.

## Задание

1. Три карточки среды (данные — таблица шага 1): номер пары, предмет, преподаватель, аудитория, время.
2. Все стили — в `style.css` (кроме переменной на карточке). Скелет уже есть, заполни TODO.
3. Bootstrap и любые готовые CSS-фреймворки запрещены.

## Проверка

`check.html` через Live Server: **10 проверок** (включая реальные вычисленные стили: цвет полоски = переменная, градиент, flex).

## Зачёт (10 баллов)

- Автопроверка — 4.
- Ручные — 4:
  - CSS прошёл [валидатор](https://jigsaw.w3.org/css-validator/#validate_by_upload);
  - переменная реально используется: и полоска, и номер берут `var(--subject-color)`, а не захардкоженный цвет;
  - один предмет — один цвет во всех карточках;
  - аккуратный код: селекторы по классам, без `!important`.
- Защита — 2: поменяй цвет «Экономики отрасли» на лету (одна правка — перекрасились и полоска, и номер).

**Бонус (+1):** замени готовые оттенки на `color-mix(in srgb, var(--subject-color) 22%, white)` —
современный CSS без ручного подбора цветов.
