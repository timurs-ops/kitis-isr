# Шаг 00 · Среда и публикация

**Цель:** к концу шага у тебя есть свой репозиторий, работающий локальный сервер и живая ссылка на GitHub Pages.
Это фундамент всего курса — без него дальше никуда.

## Задание

1. Пройди [docs/STUDENT-START.md](../../docs/STUDENT-START.md) целиком: GitHub → репозиторий из шаблона → VS Code → Live Server.
2. Открой **корень** репозитория в VS Code, нажми **Go Live**.
3. Убедись, что запускается проверка шага 1: `http://127.0.0.1:5500/steps/step-01-html/check.html`
   (красные пункты — нормально, это будущие TODO; важно, что страница проверки работает).
4. Отредактируй корневой `index.html`:
   - фамилия, имя, группа вместо `TODO`;
   - ссылка на твой GitHub;
   - `<title>` вида «Расписание КИТиС · работы Иванов».
5. Закоммить изменения (через веб-интерфейс GitHub: Add file → Upload files, или через git, если уже умеешь).
6. Включи **Settings → Pages → Deploy from a branch → main / (root)**.
7. Открой свою ссылку Pages, убедись, что визитка видна. Отправь ссылку преподавателю / в таблицу группы.

## Зачёт (ручной, 10 баллов)

| Критерий | Баллы |
|---|---|
| Pages открывается, видна визитка с твоим именем и группой | 3 |
| check.html шага 1 запускается через Live Server (покажи скриншот) | 3 |
| Репозиторий публичный, структура шаблона не сломана (data/, tools/, steps/ на месте) | 2 |
| Защита: покажи Go Live и объясни, зачем странице локальный сервер | 2 |

## Частые ошибки

- Открыл check.html двойным щелчком → `file://` → проверки не работают. Только через Go Live.
- Открыл в VS Code папку шага вместо корня → пути `../../data/` ломаются.
- Pages не включён или `index.html` не в корне репозитория.
- Забыл закоммитить: локально изменил, а на GitHub старая версия.
