# Данные для заданий

Это **реальный срез** расписания группы **ИСр24-1** за неделю **16–22 ноября 2026**, снятый с сервера колледжа
(`http://94.72.18.202:8083/cg95.htm`, обновлено 19.11.2026 11:23) и приведённый к простому учебному формату.

| Файл | Зачем |
|---|---|
| `schedule.json` | Основной файл. Шаги 3, 7 и дальше. |
| `schedule.js` | Тот же объект, но как `window.SCHEDULE = {...}` — для шагов 4–5, пока мы ещё не умеем `fetch`. |
| `empty.json` | Пустая неделя (`days: []`) — для проверки состояния «Пар нет» на шаге 7. |

## Формат

```
college, group     — название колледжа и группы
week.monday/sunday — границы недели (ISO-даты), week.label — как показать человеку
updated            — когда данные обновлены на сервере
bells.curator      — кураторский час в понедельник ("Разговоры о важном")
bells.monday       — звонки пар в понедельник (пара длится 1 ч 20 мин)
bells.other        — звонки вторник–суббота (пара длится 1 ч 30 мин)
days[]             — 7 дней, понедельник первый. У воскресенья lessons пустой.
```

День: `date` (ISO), `weekday` («Среда»), `short` («Ср»), `lessons[]`.

Пара (занятие):

| Поле | Смысл |
|---|---|
| `n` | номер «часа» на сервере, 1–7 (в понедельник 1-й час — кураторский) |
| `pair` | номер пары по звонкам; `0` = кураторский час |
| `badge` | что рисовать в кружке: `"К"` или `"1"`…`"6"` |
| `start`, `end` | время по звонкам, `"ЧЧ:ММ"` |
| `subject` | предмет |
| `teacher` | преподаватель (уже с пробелами между инициалами) |
| `room` | аудитория строкой (`"403"`, `"109м"`, `"Сп. зал 3"`) или `null` → показывай **«Дистант»** |
| `color` | цвет предмета, `#rrggbb`. Один предмет — всегда один цвет. |

## Особенности недели (специально для заданий)

- **Понедельник** — кураторский час (значок «К», 08:30–09:00), пары со 2-го «часа» и по другим звонкам.
- **Четверг и пятница** — пары без аудитории (`room: null`) → «Дистант».
- **Пятница** — «окно»: пары только 4–6.
- **Воскресенье** — пар нет (пустой массив).
- Аудитории бывают нечисловые: `109м`, `Сп. зал 3`.

## Демо-время

Чтобы не ждать настоящей пары, страницы шага 5+ поддерживают параметр `?now=`:
`index.html?now=2026-11-18T10:30` — среда, 10:30, идёт 2-я пара «Экономика отрасли», до конца 70 минут.

## Откуда цвета и чем это отличается от большого проекта

В настоящем проекте данные лежат в `data/kitis-data.js` в «сжатом» виде: словари (`groups`, `teachers`, `rooms`, `subjects`)
и массив числовых кортежей-ссылок. Специально всё «развёрнуто» в понятный JSON.
Цвета предметов на настоящем сайте закрепляет робот; в этом срезе они вычислены **запасным алгоритмом самого проекта**
(`subjectColor` из `kitis-model.js`) — спокойные, уникальные, стабильные для названия предмета.
