# Старт за один вечер (для тех, кто начинает с нуля)

Понадобится: компьютер, браузер, почта. Всё остальное — бесплатно.
Результат вечера: свой репозиторий, работающий локальный сервер и живая ссылка на твою страницу.

## 1. GitHub

1. Открой [github.com](https://github.com) → **Sign up**. Логин — желательно нормальный (но не обязательно): это твоё портфолио.
2. Подтверди почту.

## 2. Свой репозиторий из шаблона

Я выложил этот проект как **Template repository**:

1. Открой страницу шаблона.
2. Зелёная кнопка **Use this template → Create a new repository**.
3. Имя: `kitis-isr`. Видимость: **Public**. Нажми **Create repository**.

Альтернатива: скачай ZIP этого проекта и загрузи его
в свой новый репозиторий через **Add file → Upload files** (перетащи всё содержимое папки, `index.html` должен быть в корне).

## 3. VS Code + Live Server (Можно пользоваться OpenIDEA - ссылку скидывал в чат)

1. Скачай [VS Code](https://code.visualstudio.com), установи.
2. Внутри VS Code: иконка кубиков слева (Extensions) → найди **Live Server** (автор Ritwick Dey) → **Install**.

## 4. Открой проект ПРАВИЛЬНО

Это самый частый источник проблем, читай внимательно:

1. Запусти VS Code.
2. Нажми Ctrl+Shift+G → **Clone Repository**.
3. Введи адрес своего репозитория или авторизуйся через GitHub (тогда появится доступ ко всем твоим репозиториям).
4. Внизу справа нажми **Go Live**. Откроется браузер с адресом вида `http://127.0.0.1:5500`.

Альтернатива:
1. Скачай свой репозиторий на компьютер: зелёная кнопка **Code → Download ZIP**, распакуй.
2. VS Code: **File → Open Folder** → выбери **КОРЕНЬ** распакованной папки — ту, где лежат `README.md`, `data/`, `steps/`.
   **Не** отдельную папку шага! Проверки обращаются к `../../data/` и `../../tools/`.
3. Внизу справа нажми **Go Live**. Откроется браузер с адресом вида `http://127.0.0.1:5500`.

## 5. Первая проверка

Открой в браузере (через тот же адрес, не двойным щелчком!):

```
http://127.0.0.1:5500/steps/step-01-html/check.html
```

Слева — твоя будущая работа, справа — список проверок. Красные пункты — это нормально: они и есть твои TODO.

## 6. Шаг 0: визитка

Отредактируй корневой `index.html`: впиши фамилию, имя, группу, ссылку на свой GitHub, поправь `<title>`.
Подробности — в [steps/step-00-setup/README.md](../steps/step-00-setup/README.md).

## 7. Публикация на GitHub Pages

Первый раз — без git, через браузер:

1. GitHub → твой репозиторий → **Add file → Upload files** → перетащи изменённый `index.html` → **Commit changes**.
2. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
3. Через 1–2 минуты сверху появится ссылка `https://твой-логин.github.io/kitis-isr/`. Открой — там твоя визитка.

Git осваиваем позже (полный трек — отдельным модулем, экспресс — по желанию). Пока коммиты через браузер — законно.

## 8. Сдача

Ссылку на Pages отправь мне / в таблицу группы. Как сдавать каждый следующий шаг — [GRADING.md](GRADING.md).

## Если что-то не работает

| Симптом | Причина и лечение                                                                         |
|---|-------------------------------------------------------------------------------------------|
| check.html пишет про `file://` | Открыл двойным щелчком. Нужен **Go Live** и адрес `http://127.0.0.1:5500/...`             |
| Проверки «не видят» данные или стили чекера | Открыл в VS Code папку шага, а не корень репозитория. Переоткрой корень                   |
| Pages показывает 404 | Подожди 2 минуты; проверь, что `index.html` в корне репо и Pages включён для ветки `main` |
| Изменил файл — на Pages старое | Pages обновляется с задержкой до пары минут; обнови страницу с Ctrl+F5                    |
| Ничего не помогает | Скриншот ошибки + что именно делал → мне. Это не стыдно, стыдно молчать неделю            |
